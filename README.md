## 🎯 À propos du projet

**DANNY RT AMOUR** n'est pas un simple site web. C'est une plateforme éducative et personnelle conçue pour explorer les facettes de l'amour et des relations humaines. Le projet vise à promouvoir la maturité affective, la communication non-violente et le respect mutuel au sein des couples.

Le site a été développé en **Vanilla JS** (sans framework lourd) pour garantir des performances optimales, une rapidité de chargement exceptionnelle et une compatibilité totale avec les mobiles (Android/iOS) grâce à sa configuration **PWA (Progressive Web App)**.

---

## ✨ Fonctionnalités clés

- **📱 Mobile-First & Responsive** : Interface parfaitement adaptée aux smartphones, tablettes et ordinateurs.
- **🌙 Mode Sombre / Clair** : Gestion des thèmes avec mémorisation du choix de l'utilisateur via `localStorage`.
- **🔍 Moteur de recherche interne** : Filtrage dynamique des conseils et citations en temps réel.
- **📚 Bibliothèque de contenu** : Sections dédiées à la Psychologie, la Vie de couple, le Romantisme et la Fidélité.
- **📬 Contact multi-canal** : Intégration directe de Gmail, Facebook et WhatsApp pour une communication fluide.
- **⚡ PWA Ready** : Possibilité d'installer le site comme une application native sur téléphone (via le fichier `manifest.json`).

## 🛠️ Architecture Technique

Le projet est construit sur une architecture **statique, légère et sécurisée**, idéale pour un hébergement sur GitHub Pages.

```text
